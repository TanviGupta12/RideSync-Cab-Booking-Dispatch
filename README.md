# Cab Booking System

A console-based Cab Booking System developed in C++17 as a Phase 1 PBL project.

## 📌 Project Overview

The Cab Booking System is designed to simulate cab booking through a modular and organised console-based application. The project demonstrates Object-Oriented Programming and core Data Structures and Algorithms in C++17.

## 🎯 Objectives

- Develop a modular Cab Booking System using C++17
- Implement Customer, Driver, Admin, and Booking modules
- Represent locations and roads using a weighted graph
- Find shortest routes using Dijkstra's Algorithm
- Assign suitable drivers using a priority queue
- Calculate fares based on route distance
- Store booking and user data using file handling

## 🛠️ Technology Stack

- **Language:** C++17
- **IDE:** Visual Studio Code
- **Data Structures:** Graph, Priority Queue, Stack, Vector
- **Algorithms:** Dijkstra's Shortest Path Algorithm
- **File Handling:** fstream / text files
- **Version Control:** GitHub
